# Modular Rooftop Semantic Segmentation Framework

Rooftop Segmentation is a computer vision research project for semantic segmentation of rooftops from aerial imagery. The repository focuses on building a reproducible research pipeline with flexible modules, modern Python tooling, reproducible environments with automated testing, and deployment support.
